# 孩子適合什麼樂器？

慕尼克音樂新北板橋校區的探索頁。家長用手機花大約一分鐘答六題，看到孩子可能會喜歡的 2 到 3 種樂器，再一鍵打開已經帶入答案的課程報名表。

這個頁面不下定論，也不收集姓名、電話或信箱。

## 本地執行

```bash
npm install
npm run dev
```

瀏覽器打開 [http://localhost:43123](http://localhost:43123)。

```bash
npm test
npm run lint
npm run build
```

## 預約課程怎麼帶入答案

「預約課程」會打開慕尼克課程報名表的預先填入連結，並勾好：

- 學員年齡
- 學員性格屬性
- 報名動機與學習目標
- 喜歡的音樂型態
- 報名項目（這次探索出來的樂器）

畫面上的說法比較口語，送進表單的選項文字與表單原文一致。例如畫面上的「興趣與紓壓」，表單裡是「興趣與舒壓」；「華語流行與獨立樂團」對應表單的「華語流行樂語獨立樂團」。

吉他會依年齡勾選：8 歲以上同時勾木吉他與電吉他，6–7 歲勾電吉他。年紀更小、但探索結果仍出現吉他或貝斯時，也會勾上建議年齡較低的那一項，讓老師知道孩子想試的方向。

## 換成上課短片

現在每種樂器底下是占位。要換上教室影片時，編輯 `src/lib/clips.ts`：

1. 把 mp4 放到 `public/videos/`
2. 把對應的 `null` 改成 `"/videos/檔名.mp4"`
