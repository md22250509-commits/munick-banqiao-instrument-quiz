# 孩子適合什麼樂器？｜慕尼克音樂 新北板橋

給家長的一分鐘探索網頁。不是幫孩子下定論，而是看看他**可能會喜歡**爵士鼓、吉他、Bass 電貝斯、歌唱或流行鋼琴，並把答案帶進課程報名表。

本頁不收集個人資料、不需登入。引導家長預約正式課程，而不是先來試玩。

## 本機執行

```bash
npm install
npm run dev
```

瀏覽器打開 [http://127.0.0.1:43123](http://127.0.0.1:43123)。

## 部署到 Vercel

用 Vercel 匯入這個專案即可，不需要環境變數。正式網址可選填 `NEXT_PUBLIC_SITE_URL`（例如 `https://your-domain.vercel.app`），分享到 LINE／Facebook 時會用到。

## 之後換成上課短片

編輯 `src/lib/videos.ts`。每個樂器的 `src` 可填：

- 影片檔：先放到 `public/videos/`，再填 `/videos/drums.mp4`
- YouTube 連結：直接貼完整網址

現在是占位畫面，標示「上課短片即將上架」。

## 報名表預先填入

結果頁的「預約課程」會打開慕尼克課程報名表，並帶入：

- 學員年齡
- 學員性格屬性
- 喜歡的音樂型態
- 報名動機與學習目標
- 報名項目（推薦的 2–3 種樂器）

選項文字與表單完全一致。家長只需補姓名、電話等其餘欄位。
