# 孩子適合什麼樂器？

慕尼克音樂新北板橋校區的探索頁。家長用手機花大約一分鐘答七題，看到孩子可能會喜歡的 2 到 3 種樂器，再一鍵打開已經帶入答案的課程報名表。

這個頁面不下定論，也不收集姓名、電話或信箱。

## 本地執行

```bash
npm install
npm run dev
```

瀏覽器打開 [http://localhost:43123](http://localhost:43123)。

```bash
npm test
npm run lint
npm run build
```

## 預約課程怎麼帶入答案

「預約課程」會打開慕尼克課程報名表的預先填入連結，並勾好：

- 學員年齡（畫面上問的是年級，例如「二、三年級」）
- 學員性格屬性
- 報名動機與學習目標
- 喜歡的音樂型態
- 報名項目（這次探索出來的樂器）

畫面上的說法比較口語，送進表單的選項文字與表單原文一致。例如畫面上的「興趣與紓壓」，表單裡是「興趣與舒壓」；「華語流行與獨立樂團」對應表單的「華語流行樂語獨立樂團」。

爵士鼓一定會出現在結果裡。第 3 題選敲敲打打，或第 4 題選跟著打拍子時，爵士鼓排在第一個。木吉他、電吉他和 Bass 是同一類，只看兩個條件：一年級以上，而且第 7 題選了「孩子自己主動想學」。兩個都符合才推薦。喜歡唱歌或會跟著唱的答案，會優先推薦歌唱和流行鋼琴。

這一類若出現在結果裡，報名表依年級勾選：大約 8 歲以上同時勾木吉他、電吉他和貝斯，6–7 歲勾電吉他。

## 換成上課短片

現在每種樂器底下是占位。要換上教室影片時，編輯 `src/lib/clips.ts`：

1. 把 mp4 放到 `public/videos/`
2. 把對應的 `null` 改成 `"/videos/檔名.mp4"`
